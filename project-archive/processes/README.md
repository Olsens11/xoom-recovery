# Xoom process reference handbook

**Start here:** [processes/DIRECTORY.md](DIRECTORY.md), which links to the reusable recovery, Toolkit, QA/rollback, agent-startup and documentation-maintenance references.

Read the [mandatory leaf-to-root documentation roll-up checklist](DOCUMENTATION-ROLLUP-CHECKLIST.md) before committing changes. The [optional validation helper](../../scripts/check_documentation_rollup.py) checks whether parent directory records were updated in the same change set.

**Important distinction:** engineering steps recorded here are generally standardized **examples** that may be replaced by better validated approaches. The mandate to maintain accurate, linked documentation [is binding](DOCUMENTATION-MAINTENANCE.md). Destructive actions still require explicit authorization and integrity safeguards.
