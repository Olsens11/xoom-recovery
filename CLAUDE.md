# Xoom agent entry point

**Mandatory on entry:** read [AGENTS.md](AGENTS.md). It specifies onboarding, documentation maintenance requirements, including full leaf-to-root propagation on every documentation round, evidence hierarchy, safety/approval gates and handoff expectations.

Then consult [the project directory tree](project-archive/DIRECTORY.md) and [the process reference handbook](project-archive/processes/DIRECTORY.md).

The engineering procedures are **reference practices**, not rigid mandatory implementations; accurate and timely documentation, explicit authorization for destructive actions, and protection of historical evidence are mandatory.
