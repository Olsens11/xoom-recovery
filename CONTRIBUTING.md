# Contributing to Xoom recovery and Toolkit

Before any Xoom development, read [AGENTS.md](AGENTS.md), the [authoritative directory hierarchy](project-archive/DIRECTORY.md) and the [continuous documentation mandate](project-archive/processes/DOCUMENTATION-MAINTENANCE.md).

Every documentation round must update the leaf and ALL ancestor DIRECTORY.md files up through the project root, keeping latest-child links, current status and supersession accurate. A review showing no change still gets a dated evidence note. Preserve exact source and artifact provenance, and record decisions and QA separately. The [process handbook](project-archive/processes/DIRECTORY.md) documents familiar proven patterns but is **not a rigid mandate to use particular build scripts or test harnesses**.

Do not publish private archives, credentials, raw recovery partition images or third-party binary toolchains. Flashing the Xoom requires separate approval for the exact recovery image and target.
